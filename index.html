video-publisher

video-publisher is a personal desktop tool. Its owner uses it to create short vertical videos and to upload them to the owner's own accounts on YouTube, TikTok and Instagram.

What it does

The tool runs only on the owner's computer. After the owner connects an account through the platform's official sign-in screen (OAuth), the owner picks a finished video, reviews the title, description and privacy setting, and presses a button to send it. The tool then calls the official APIs:

  • YouTube Data API v3 (videos.insert) to upload the video to the owner's YouTube channel.
  • TikTok Content Posting API to send the video to the owner's TikTok inbox as a draft, which the owner finishes and posts from the TikTok app.
  • Instagram API to publish a Reel on the owner's Instagram professional account.

Nothing is uploaded without an explicit action by the owner. The tool does not access other people's accounts, does not read private messages, and does not like, follow or comment automatically.

Who can use it

video-publisher is not a public service. It is used only by its developer for the developer's own channels.
