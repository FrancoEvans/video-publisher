Privacy Policy

Last updated: November 21, 2026

This policy explains how video-publisher ("the tool") handles data. The tool is a personal application that runs on its owner's computer and is used only by its developer for the developer's own accounts.

Data the tool accesses

  • Google / YouTube: the permission https://www.googleapis.com/auth/youtube.upload, used only to upload videos to the connected YouTube channel. The tool does not read the channel's videos, comments, subscribers or analytics.
  • TikTok: basic profile information (user.info.basic) to show which account is connected, and video.upload to send videos as drafts to that account.
  • Instagram: basic profile information and the permission to publish content on the connected professional account.

How data is stored

Access tokens and refresh tokens returned by each platform are stored only on the owner's computer, in the tool's local data folder. They are not sent to any server operated by the developer, not sold, not shared with third parties and not used for advertising. Videos and their descriptions are created by the owner and are sent only to the platform the owner chooses.

How data is used

Data obtained through the platforms' APIs is used only to perform the upload the owner requested and to show the result (for example, the ID or link of the uploaded video).

Retention and deletion

Tokens are kept until the owner disconnects the account in the tool, which deletes them from the local folder. Access can also be revoked at any time from each platform:

  • Google: https://myaccount.google.com/permissions (see also the Google security settings page).
  • TikTok: Settings and privacy > Security > Apps and services permissions.
  • Instagram: Settings > Website permissions > Apps and websites.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Cookies and analytics

This website and the tool do not use cookies, trackers or analytics.
